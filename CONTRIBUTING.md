# Contributing

Contributions are welcome.

## Development

The project intentionally has no build system. Keep changes compatible with modern evergreen browsers and avoid dependencies unless they provide clear value.

## Pull requests

1. Create a focused branch.
2. Keep UI changes responsive on mobile and desktop.
3. Verify numerical changes against a small hand-calculated dataset.
4. Describe the reason for the change and how it was tested.

## Ideas

Useful contributions include weighted regression, uncertainty calculations, CSV import, accessibility improvements, and additional calibration diagnostics.
